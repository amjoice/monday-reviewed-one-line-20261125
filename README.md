## What it does

`main.py` (Python 3.13, standard library only) writes one funny one-line review of the entrant's own Monday — a single line, under 200 characters — to `/output/entry.txt`:

> One star: Monday's 9 a.m. standup ran 40 minutes, decided nothing, and ended by scheduling a meeting to decide when to decide.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
